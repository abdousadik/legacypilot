# LegacyPilot

LegacyPilot is a developer tool focused on safely analyzing, testing, and modernizing legacy backend applications.

The project is also a long-term engineering learning project covering modern backend architecture, testing, AI engineering, cloud infrastructure, DevOps, and production engineering.

## Long-Term Direction

LegacyPilot should eventually be able to help developers:

- analyze legacy applications
- identify risky code
- discover missing tests
- generate and evaluate tests
- run static analysis
- run mutation testing
- detect deprecated framework/code usage
- propose safe modernization steps
- produce measurable reports
- integrate with Git repositories and CI/CD

The project starts with PHP/Symfony but should be designed so other ecosystems can be supported later.
