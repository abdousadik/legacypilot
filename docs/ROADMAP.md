# LegacyPilot Engineering Roadmap

## Career Goal

Progress from:

PHP / Symfony Backend Developer

toward:

Senior Backend / Platform Engineer with Cloud and AI engineering skills.

The goal is not to collect technologies. Each technology should be learned by using it in a real part of LegacyPilot.

---

## Phase 0 — Engineering Foundation

Learn and establish:

- modern PHP
- modern Symfony
- Git workflow
- Docker development
- application architecture fundamentals

Deliverable:

A clean, modern, reproducible Symfony application.

---

## Phase 1 — Engineering Quality

Learn:

- PHPUnit
- integration testing
- PHPStan
- Rector
- Infection mutation testing
- clean architecture
- dependency boundaries
- maintainable code design

Deliverable:

A backend with strong automated quality guarantees.

---

## Phase 2 — LegacyPilot MVP

Build:

- CLI interface
- repository scanner
- project detection
- test discovery
- static-analysis orchestration
- code-quality reports
- modernization reports

Deliverable:

A useful standalone developer tool without requiring AI.

---

## Phase 3 — AI Engineering

Learn:

- Python
- FastAPI
- LLM APIs
- structured outputs
- tool calling
- context engineering
- embeddings
- retrieval
- evaluations
- model routing
- guardrails
- cost management
- agent workflows

Deliverable:

AI-assisted repository analysis with measurable quality.

---

## Phase 4 — Production Backend Engineering

Learn:

- PostgreSQL
- advanced SQL
- Redis
- queues
- workers
- asynchronous processing
- idempotency
- distributed locks
- retries
- eventual consistency
- event-driven architecture

Deliverable:

A scalable asynchronous analysis platform.

---

## Phase 5 — Infrastructure & Platform Engineering

Learn:

- advanced Docker
- CI/CD
- GitHub Actions
- AWS
- Terraform
- Kubernetes fundamentals
- OpenTelemetry
- logging
- metrics
- tracing
- production security

Deliverable:

A real production deployment with infrastructure as code.

---

## Phase 6 — Product Layer

Learn enough frontend engineering to ship the product:

- TypeScript
- React
- Next.js

Build:

- LegacyPilot web dashboard
- authentication
- projects
- analysis history
- reports
- GitHub integration
- billing if commercially justified

---

## Phase 7 — International Career Packaging

Create:

- professional portfolio
- LegacyPilot technical case study
- YONVO technical case study
- engineering articles
- open-source releases
- architecture documentation

Prepare for:

- backend interviews
- system-design interviews
- international applications
- European and international remote roles

---

## Rules

1. Do not jump phases because a new technology looks interesting.
2. Every major skill must be applied in working code.
3. Prefer depth over collecting frameworks.
4. LegacyPilot must remain independent from employer intellectual property.
5. Architecture decisions must be documented.
6. Every checkpoint needs explicit PASS criteria.
7. Working software is more important than watching courses.
